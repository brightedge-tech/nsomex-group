# NSOMEX Orbit

NSOMEX Orbit is a modern starter experience for a future-facing platform. This repository now contains a polished Next.js foundation with an accessible landing experience and a structure that can grow into a richer product over time.

## What is included

- A modern Next.js App Router setup with TypeScript and Tailwind CSS
- A branded landing page for NSOMEX Orbit
- A clear structure for future feature work and product expansion

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the app.

## Validation

Run the checks below before shipping changes:

```bash
npm run lint
npm run build
```
